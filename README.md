# Марк / MDRK Studio

Разработчик и основатель [МДРК Студио](https://mdrkstudio.ru).

Создаю веб-приложения, внутренние системы и инструменты автоматизации. Работаю с интерфейсом, серверной логикой, интеграциями и desktop-приложениями. Отдельное направление - интерактивная 3D-графика и игры.

В проектах связываю задачу бизнеса с устройством продукта: какие данные нужны, что делает человек, какие операции можно автоматизировать и как всё это показать в интерфейсе.

## Код проектов

- [Telegram Ollama Bot](https://github.com/mdrkstudio/telegram-ollama-bot) - Python-бот с ответами через Ollama и режимом работы из терминала.
- [Orbital Archive](https://github.com/mdrkstudio/orbital-archive) - процедурный подводный мир на Three.js и GLSL с непрерывным маршрутом камеры.
- [Hand Gesture Control](https://github.com/mdrkstudio/hand-gesture-control) - управление macOS жестами: громкость, музыка, прокрутка и рабочие столы на Python, MediaPipe и OpenCV.
- [AXIOM](https://github.com/mdrkstudio/axiom-industrial) - интерактивная 3D-презентация промышленного объекта с маршрутом камеры, оборудованием и схемой связей.
- [Support Analyst](https://github.com/mdrkstudio/support-analyst) - импорт обращений, группы проблем, повторы и отчёты для команды.
- [Website Toolkit](https://github.com/mdrkstudio/website-toolkit) - Swift-библиотека нормализации адресов сайтов и извлечения контактов из HTML.
- [Print Kit](https://github.com/mdrkstudio/print-kit) - карточки гостей, номера столов и рассадка из CSV, JSON и Excel.

Исходники этих проектов доступны по лицензии PolyForm Noncommercial 1.0.0.
